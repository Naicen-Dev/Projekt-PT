# Stadtbibliothek Buxtehude

Willkommen im Repository der **Stadtbibliothek Buxtehude**. Dieses Projekt ist ein Prototyp für die neue Website der Bibliothek, der darauf abzielt, den Nutzern einen einfachen Zugang zu Büchern, Informationen und ihrem Konto zu ermöglichen.

## 📖 Über das Projekt

Die Website dient als digitale Anlaufstelle für Bibliotheksnutzer. Aktuell liegt der Fokus auf der Strukturierung der Inhalte mittels HTML5.

### Aktuelle Funktionen (Prototyp)

*   **Startseite**: Übersichtliche Landing Page mit Navigation.
*   **Katalogsuche**: Vorbereitetes Suchfeld für Titel, Autoren oder ISBN.
*   **Informationen**: Anzeige der aktuellen Öffnungszeiten.
*   **Navigation**: Menüstruktur für Suche, Infos und Benutzerkonto.
