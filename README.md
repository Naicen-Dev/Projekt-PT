# Stadtbibliothek Buxtehude

Willkommen im Repository der **Stadtbibliothek Buxtehude**. Dieses Projekt ist ein Prototyp für die neue Website der Bibliothek, der darauf abzielt, den Nutzern einen einfachen Zugang zu Büchern, Informationen und ihrem Konto zu ermöglichen.

## 📖 Über das Projekt

Die Website dient als digitale Anlaufstelle für Bibliotheksnutzer. Das Projekt wurde von einem reinen HTML-Prototyp auf ein dynamisches System mit PHP und einer MariaDB-Datenbank umgestellt.

### Aktuelle Funktionen (Prototyp)

*   **Startseite**: Übersichtliche Landing Page mit Navigation und responsivem Design.
*   **Katalogsuche mit AJAX**: Dynamisches Suchfeld für Titel, Autoren oder ISBN mit benutzerfreundlichen Live-Vorschlägen.
*   **Medienübersicht**: Seite zur Anzeige aller verfügbaren Medien (`medien.php`).
*   **Datenbankanbindung**: MariaDB-Datenbank zur Verwaltung von Autoren, Benutzern und Medien (`bibliothek.sql`, `db_connect.php`).
*   **Informationen**: Anzeige der aktuellen Öffnungszeiten.
*   **Navigation**: Menüstruktur für Startseite, Alle Medien, Infos und Benutzerkonto.

## 🛠️ Eingesetzte Technologien
*   **Frontend**: HTML5, CSS3, JavaScript (Fetch API für Suchvorschläge)
*   **Backend**: PHP
*   **Datenbank**: MariaDB / MySQL
